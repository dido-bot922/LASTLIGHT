# LASTLIGHT

Protótipo vertical slice em Godot 4 de uma aventura científica de ficção científica em primeira pessoa.

## Como executar
1. Instale Godot 4.3 ou superior.
2. Abra `project.godot` no editor.
3. Pressione F6/F5 para iniciar a sequência **Vigília Zero**.

## Primeiro protótipo jogável
- Caminhada em primeira pessoa dentro do módulo de preparação da nave.
- Painéis de energia, suporte de vida, combustível e comunicações.
- Recursos simulados em tempo real, alarmes e feedback visual.
- Terminal científico para iniciar a leitura do fenômeno LASTLIGHT.
- Arquitetura modular para adicionar Terra, voo, planetas e IA da nave.

## Controles
WASD / setas: movimentar · mouse: olhar · Shift: correr · E: operar equipamento · Esc: liberar mouse
