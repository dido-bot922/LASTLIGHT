# Plano de produção de alta qualidade

A primeira pessoa agora é a camada principal da experiência, não um recurso secundário. O jogador recebe:

- controle de movimento com stamina;
- view model de mãos;
- roteamento de animação;
- feedback e legendas;
- prompts para teclado e controle;
- cenas narrativas que não tiram o controle do jogador;
- manifesto de assets para personagens, animações e materiais UHD;
- checklist de produção verificável.

Os assets UHD continuam sendo arquivos binários que precisam ser fornecidos/importados. O projeto não inventa modelos ou texturas inexistentes.

A meta de 100.000 linhas permanece uma meta de produção e não será atingida por cópia, preenchimento ou geradores artificiais. A contagem deve considerar código GDScript real, integração e testes.
