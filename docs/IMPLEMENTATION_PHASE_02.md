# Integração do núcleo avançado

O pacote desta etapa adiciona uma camada funcional e integra os novos sistemas via Autoload:

- `RuntimeBridge`: conecta recursos, falhas, ciência, navegação, IA e salvamento;
- `DiagnosticConsole`: valida os subsistemas carregados;
- `TutorialDirector`: orienta o primeiro ciclo de jogo;
- `ChoiceSystem`: decisões com efeitos reais na missão;
- `AudioDirector`: canais e alertas contextuais;
- `AtmosphereDirector`: evolução de tensão e eventos ambientais;
- `ResearchArchive`: registros pesquisáveis da missão.

A meta de 10.000 linhas deve ser atingida por conteúdo funcional adicional, nunca por repetição artificial. Este commit aumenta a base e corrige a integração, mas a contagem total deve ser verificada com uma ferramenta de linha de comando no clone do repositório antes de ser declarada como concluída.
